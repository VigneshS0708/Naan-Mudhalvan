# Naan-Mudhalvan Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer is an IT service management automation project designed to simplify and accelerate the process of ordering standard laptops for employees. The project uses ServiceNow Flow Designer to automate the procurement workflow from request submission through approval, fulfillment, and status tracking.

The solution allows employees or authorized users to submit a standard laptop request through a service catalog. Based on predefined conditions such as employee role, department, and laptop type, the workflow automatically validates the request and routes it to the appropriate approver. Once approval is received, Flow Designer triggers the necessary procurement and fulfillment activities, updates the request status, and notifies relevant stakeholders.

The automation reduces manual intervention, eliminates repetitive administrative tasks, and provides better visibility into the procurement lifecycle. It also helps ensure that standard laptop requests follow consistent approval and fulfillment procedures.

Key Objectives
Automate the standard laptop procurement process.

Reduce manual processing and approval delays.

Standardize laptop request and approval procedures.

Provide real-time visibility into request status.

Automatically notify employees, approvers, and procurement teams.

Maintain an auditable record of procurement activities.

Improve overall efficiency and accuracy in IT asset procurement.

Expected Outcome
The project will provide a streamlined, automated laptop-ordering process that improves operational efficiency, reduces processing time, minimizes human errors, and enhances the employee experience. The resulting workflow can also serve as a foundation for automating other standardized IT procurement requests.
